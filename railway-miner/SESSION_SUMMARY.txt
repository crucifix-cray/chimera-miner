ROOT CAUSES
================================================================================

1. RAILWAY RAILPACK OVERRIDE
   - Railway auto-detects Python (requirements.txt)
   - Ignores Dockerfile, nixpacks.toml, railway.toml
   - Uses Railpack which doesn't install system packages

2. INSUFFICIENT MEMORY
   - Railway free/basic: 1GB RAM
   - Firefox + Playwright + Xvfb: ~800MB-1GB
   - Browser crashes or hangs on page loads
   - Need 2GB+ RAM minimum

3. MISLEADING TOOLS  
   - railway ssh connects to HOST machine, not container
   - railway logs only shows "Starting Container"
   - No access to actual deployment logs via CLI
